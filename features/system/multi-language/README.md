# Módulo `:multi-language`

Módulo reutilizável para **Internacionalização Avançada (i18n)** em tempo de execução.

---

## 🎯 Objetivo e Funcionalidades

- **Troca de Idioma**: Suporte a múltiplos idiomas (PT, ES, EN) sem reiniciar o app.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":multi-language"))
}
```
