# Módulo `:stores`

Módulo reutilizável para **Seletor de Filiais, Multi-Lojas e Localizador de Unidades via GPS**.

---

## 🎯 Objetivo e Funcionalidades

- **Seletor de Filiais**: Seleção automática da loja/unidade mais próxima do usuário por GPS.
- **Detalhes da Unidade**: Endereço, foto da fachada, telefone e horário de funcionamento de cada filial.
- **Rota no Mapa**: Botão direto para traçar rota no Google Maps ou Waze.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":stores"))
}
```
