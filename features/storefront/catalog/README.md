# Módulo `:catalog`

Módulo reutilizável para **Catálogo de Produtos, Cardápios Digitais (Pizzarias/Padarias/Restaurantes) e Seleção de Adicionais**.

---

## 🎯 Objetivo e Funcionalidades

- **Categorias e Listagem**: Listagem por guias/categorias (ex: Pizzas Salgadas, Pizzas Doces, Bebidas).
- **Montador de Adicionais**: Seleção flexível de tamanhos (P/M/G), sabores meio-a-meio, bordas recheadas e ingredientes extras.
- **Modal de Detalhes**: Galeria de fotos, descrição do produto e seletor de quantidade.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":catalog"))
}
```
