# Módulo `:analytics`

Módulo reutilizável para **Painel Administrativo Mobile (Dashboard de BI para o Lojista)**.

---

## 🎯 Objetivo e Funcionalidades

- **Dashboard de Vendas**: Faturamento do dia, total de pedidos e ticket médio.
- **Fechamento de Caixa**: Acompanhamento de pagamentos em Dinheiro, PIX e Cartão.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":analytics"))
}
```
