# Módulo `:subscriptions`

Módulo reutilizável para **Gestão de Assinaturas e Cobranças Recorrentes (Clubes de Membros)**.

---

## 🎯 Objetivo e Funcionalidades

- **Planos Recorrentes**: Gerenciamento de assinaturas mensais ou semanais via Cartão de Crédito ou PIX.
- **Status do Plano**: Validação de vigência da assinatura do usuário.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":subscriptions"))
}
```
