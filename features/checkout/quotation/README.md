# Módulo `:quotation`

Módulo reutilizável para **Solicitação de Orçamentos e Serviços com Anexo de Fotos**.

---

## 🎯 Objetivo e Funcionalidades

- **Formulário de Solicitação**: Descrição do serviço com anexo de imagens do problema/projeto.
- **Aprovação de Orçamentos**: Aceite e assinatura do orçamento diretamente pelo aplicativo.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":quotation"))
}
```
