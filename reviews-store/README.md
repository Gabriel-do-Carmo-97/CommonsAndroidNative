# Módulo `:reviews-store`

Módulo reutilizável para **Avaliação de Pedidos, Produtos e Depoimentos do Comércio**.

---

## 🎯 Objetivo e Funcionalidades

- **Avaliação de Pedidos**: Avaliação por estrelas (1 a 5) do atendimento e da entrega recebida.
- **Feedback Interno**: Envio de comentários do cliente direto para o comerciante para controle de qualidade.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":reviews-store"))
}
```
