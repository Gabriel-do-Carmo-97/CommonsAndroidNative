# Módulo `:dispatch`

Módulo reutilizável para **Motor de Alocação de Pedidos e Roteirização (Matching)**.

---

## 🎯 Objetivo e Funcionalidades

- **Alocação Inteligente**: Atribuição automática de entregas para o motoboy mais próximo.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":dispatch"))
}
```
