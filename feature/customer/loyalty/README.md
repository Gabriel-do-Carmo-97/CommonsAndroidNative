# Módulo `:loyalty`

Módulo reutilizável para **Cartão Fidelidade, Carimbo Digital, Clube de Pontos e Cashback**.

---

## 🎯 Objetivo e Funcionalidades

- **Cartão Carimbo Digital**: "Junte 10 selos/carimbos e ganhe 1 prêmio".
- **Saldo de Cashback**: Porcentagem da compra revertida em desconto na próxima visita.
- **Resgate de Prêmios**: Extrato de pontos acumulados e catálogo de recompensas.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":loyalty"))
}
```
