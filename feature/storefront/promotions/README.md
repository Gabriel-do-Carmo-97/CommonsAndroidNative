# Módulo `:promotions`

Módulo reutilizável para **Cupons de Desconto, Banners Promocionais e Ofertas Relâmpago**.

---

## 🎯 Objetivo e Funcionalidades

- **Validador de Cupons**: Verificação de regras (primeira compra, frete grátis, valor mínimo, limite de uso).
- **Banners & Carrossel**: Carrossel promocional na Home do app.
- **Ofertas Relâmpago**: Contador regressivo de ofertas por tempo limitado.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":promotions"))
}
```
