# Módulo `:emergency`

Módulo reutilizável para **Botão de Pânico e Alerta Silencioso de Segurança**.

---

## 🎯 Objetivo e Funcionalidades

- **Alerta de Emergência**: Transmissão imediata de localização GPS para central ou contatos de confiança.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":emergency"))
}
```
