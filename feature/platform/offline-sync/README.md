# Módulo `:offline-sync`

Módulo reutilizável para **Sincronização Offline-First Avançada**.

---

## 🎯 Objetivo e Funcionalidades

- **Operação sem Internet**: Persistência de dados locais e enfileiramento de requisições para envio ao reconectar.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":offline-sync"))
}
```
