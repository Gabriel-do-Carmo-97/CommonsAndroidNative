# Módulo `:driver-app`

Módulo reutilizável para **Aplicativo Operacional do Entregador / Gestão de Rotas (Logística)**.

---

## 🎯 Objetivo e Funcionalidades

- **Aceitação de Corridas/Entregas**: Listagem de pedidos em lote para o motoboy.
- **Navegação e Status**: Otimização de rotas e sinalização de entrega concluída.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":driver-app"))
}
```
