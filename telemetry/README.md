# Módulo `:telemetry`

Módulo reutilizável para **Rastreamento GPS em Background (Foreground Service)**.

---

## 🎯 Objetivo e Funcionalidades

- **Live Tracking**: Captura contínua de coordenadas geográficas de alta precisão com otimização de bateria.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":telemetry"))
}
```
