# Módulo `:scheduling`

Módulo reutilizável para **Agendamento de Horários e Serviços (Barbearias, Salões, Petshops, Consultórios)**.

---

## 🎯 Objetivo e Funcionalidades

- **Calendário de Agendamento**: Exibição de datas e horários disponíveis em tempo real.
- **Seleção de Profissionais**: Escolha do atendente/profissional desejado.
- **Lembretes e Reagendamento**: Notificação de lembrete 1 hora antes e opção de cancelamento/reagendamento.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":scheduling"))
}
```
