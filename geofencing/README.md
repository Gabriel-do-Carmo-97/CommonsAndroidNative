# Módulo `:geofencing`

Módulo reutilizável para **Cercas Virtuais Automáticas (Geofences)**.

---

## 🎯 Objetivo e Funcionalidades

- **Zonas Geográficas**: Delimitação de perímetros e disparo de eventos ao entrar/sair de uma área.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":geofencing"))
}
```
