# 🎟️ Commercial Bundle Domain: `events`

Esta pasta agrupa os pacotes comerciais de **Eventos & Ingressos** da WGC, divididos em três tiers (`basic`, `standard`, `pro`).

---

## 🏛️ Visão Geral dos Tiers e Diferenças

| Tier | Perfil do Cliente | Módulos e Recursos Agregados |
| :--- | :--- | :--- |
| **`basic`** | Apps de participantes | Autenticação e perfil. |
| **`standard`** | Festivais e Shows | Programação, venda de ingressos e notificações. |
| **`pro`** | Grandes convenções | Check-in via QR Code (ML Kit), chat, mapas e analytics. |
