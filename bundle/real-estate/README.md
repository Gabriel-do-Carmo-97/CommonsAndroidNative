# 🏢 Commercial Bundle Domain: `real-estate`

Esta pasta agrupa os pacotes comerciais de **Imobiliário** da WGC, divididos em três tiers (`basic`, `standard`, `pro`).

---

## 🏛️ Visão Geral dos Tiers e Diferenças

| Tier | Perfil do Cliente | Módulos e Recursos Agregados |
| :--- | :--- | :--- |
| **`basic`** | Imobiliárias de entrada | Catálogo de imóveis e busca. |
| **`standard`** | Corretoras | Mapas, localização de imóveis e agendamento de visitas. |
| **`pro`** | Grandes construtoras | Tour virtual, chat com corretores e mapas offline. |
