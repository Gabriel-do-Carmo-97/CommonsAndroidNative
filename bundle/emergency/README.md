# 🚨 Commercial Bundle Domain: `emergency`

Esta pasta agrupa os pacotes comerciais de **Emergência & Segurança** da WGC, divididos em três tiers (`basic`, `standard`, `pro`).

---

## 🏛️ Visão Geral dos Tiers e Diferenças

| Tier | Perfil do Cliente | Módulos e Recursos Agregados |
| :--- | :--- | :--- |
| **`basic`** | Alertas simples | Botão de pânico básico. |
| **`standard`** | Segurança pessoal | Botão de pânico com envio de coordenadas GPS. |
| **`pro`** | Centrais de monitoramento | Botão de pânico, telemetria em tempo real, geofencing e emergência. |
