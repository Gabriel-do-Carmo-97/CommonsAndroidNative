# Módulo `:media-picker`

Módulo reutilizável para **Captura de Mídia, Seletor de Fotos/Vídeos, Câmera e Leitor de QR Code / Código de Barras**.

---

## 🎯 Objetivo e Funcionalidades

- **Photo & Video Picker**: Integração nativa com o PhotoPicker Android e galeria.
- **Câmera via CameraX**: Captura de foto com controle de flash, troca de câmera e galeria.
- **Compressão de Imagens**: Otimização e redimensionamento automático de imagens antes do upload.
- **Leitor ML Kit**: Leitura rápida de QR Code (PIX, Links) e Código de Barras de produtos.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":media-picker"))
}
```
