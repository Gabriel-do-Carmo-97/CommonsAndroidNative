# Módulo `:whatsapp-direct`

Módulo reutilizável para **Envio Direto de Pedidos, Agendamentos e Dúvidas para o WhatsApp do Comércio**.

---

## 🎯 Objetivo e Funcionalidades

- **Mensagem Formatada**: Geração de texto estruturado automático com o resumo do carrinho ou agendamento para o WhatsApp Business.
- **Botão Flutuante de Suporte**: Acesso rápido ao atendimento no WhatsApp em qualquer tela do app.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":whatsapp-direct"))
}
```
