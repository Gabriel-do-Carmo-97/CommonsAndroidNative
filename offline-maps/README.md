# Módulo `:offline-maps`

Módulo reutilizável para **Navegação Turn-by-Turn e Mapas Offline**.

---

## 🎯 Objetivo e Funcionalidades

- **Mapas sem Internet**: Cache local de mapas e rotas para áreas com sombra de sinal.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":offline-maps"))
}
```
