# Módulo `:ai-assistant`

Módulo reutilizável para **Assistente de Inteligência Artificial e Chatbot (Vertex AI / Gemini)**.

---

## 🎯 Objetivo e Funcionalidades

- **Chatbot Inteligente**: Atendimento automatizado e recomendação de produtos via IA.

---

## 📦 Como Usar

```kotlin
dependencies {
    implementation(project(":ai-assistant"))
}
```
